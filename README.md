# Desert Tourism LLC Frontend 

Open `index.html` in a browser to view the demo.

## Current frontend behaviour
- The enquiry form opens WhatsApp with the customer's entered details.
- Buttons scroll to the enquiry form.
- Contact, email and social links are clickable.
- No database or backend is required for this demo.

For a production website later, a backend can be added for database storage, email notifications, payments and an admin dashboard.
